GITHUB'A GÖNDERME
1) Bu paketteki main.go ve web klasöründeki 3 dosyayı mevcut projenizdeki dosyaların üzerine kopyalayın.
2) README.md dosyasını repo köküne koyun.
3) Test: go test ./...
4) EXE: go build -trimpath -ldflags="-H=windowsgui -s -w" -o "Arazi-Cikis-Cetveli.exe" .
5) git add .
6) git commit -m "v1.1.0 geliştirici bilgisi ve ilk açılış bildirimi"
7) git push
8) GitHub Releases bölümünde v1.1.0 etiketiyle yeni release oluşturun ve yeni EXE'yi yükleyin.
